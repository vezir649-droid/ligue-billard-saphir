# Règles du projet LigueBillardSaphir

## Synchronisation GitHub
- Systématiquement après avoir effectué et vérifié des modifications dans le code du projet, créer un commit clair et pousser les changements sur GitHub (`git push origin main`), sauf indication contraire de l'utilisateur ou s'il s'agit d'un travail temporaire/exploratoire non destiné à être publié.
